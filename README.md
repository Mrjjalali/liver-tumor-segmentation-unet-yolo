# سگمنتیشن کبد و تومور — پایپ‌لاین دو مرحله‌ای (U-Net + YOLOv11-seg)

یک پایپ‌لاین سگمنتیشن تصاویر پزشکی دو مرحله‌ای برای سی‌تی‌اسکن‌های کبد: ابتدا یک مدل U-Net کبد رو سگمنت می‌کنه، سپس یک مدل YOLOv11-seg تومورها رو در داخل ناحیه‌ی کبد شناسایی و سگمنت می‌کنه.

## معرفی کلی

سگمنتیشن تومور کبدی به دلیل عدم توازن شدید کلاس‌ها (class imbalance) کار چالش‌برانگیزیه — تومورها معمولاً بخش بسیار کوچیکی از هر اسلایس سی‌تی رو اشغال می‌کنن. به‌جای آموزش یک مدل واحد برای پیدا کردن تومورها در کل تصویر، این پروژه از یک رویکرد دو مرحله‌ای استفاده می‌کنه:

1. **مرحله ۱ — سگمنتیشن کبد (U-Net):** یک U-Net سفارشی، کبد رو از اسلایس‌های کامل سی‌تی سگمنت می‌کنه.
2. **مرحله ۲ — سگمنتیشن تومور (YOLOv11-seg):** ماسک کبد پیش‌بینی‌شده روی تصویر اصلی اعمال می‌شه (هر چیزی خارج از ناحیه‌ی کبد صفر می‌شه)، و یک مدل YOLOv11-seg آموزش داده می‌شه تا تومورها رو فقط در این ناحیه‌ی ماسک‌شده‌ی کبد شناسایی کنه — که فضای جستجو و مشکل عدم توازن کلاس رو به‌شدت کاهش می‌ده.

## دیتاست

* **منبع:** [LiTS — Liver Tumor Segmentation](https://www.kaggle.com/datasets/andrewmvd/lits-png) (کاگل، نسخه‌ی تبدیل‌شده به PNG از دیتاست اصلی چالش LiTS17)
* ۱۳۰ حجم (volume) سی‌تی، تبدیل‌شده به اسلایس‌های دوبعدی axial با فرمت PNG
* هر اسلایس یک ماسک کبد و یک ماسک ضایعه (تومور) متناظر داره
* تقسیم‌بندی train/validation بر اساس شناسه‌ی بیمار (نه بر اساس اسلایس) انجام شده تا از نشت داده (data leakage) بین اسلایس‌های مجاور یک بیمار جلوگیری بشه

## پایپ‌لاین

### مرحله ۱: سگمنتیشن کبد (U-Net)

* U-Net سفارشی، کانال‌های انکودر ۳۲→۶۴→۱۲۸→۲۵۶→۵۱۲، دیکودر متقارن با skip connection
* ورودی: اسلایس‌های ۲۵۶×۲۵۶ سی‌تی به‌صورت grayscale، نرمالایز شده به بازه‌ی [۰, ۱]
* تابع loss: ترکیب BCE + Dice loss
* بهینه‌ساز: Adam (lr=1e-4)
* نتیجه: ضریب Dice روی validation ≈ ۰.۹۳

### مرحله ۲: سگمنتیشن تومور (YOLOv11-seg)

* ماسک کبد پیش‌بینی‌شده توسط مرحله‌ی ۱ روی اسلایس خام سی‌تی اعمال می‌شه (ضرب عنصر‌به‌عنصر)، و هر چیزی خارج از کبد صفر می‌شه
* ماسک‌های تومور از فرمت PNG باینری به فرمت پلی‌گان YOLO تبدیل می‌شن، از طریق استخراج contour (با `findContours` از OpenCV)
* مدل: `yolo11n-seg` (Ultralytics)، به مدت ۳۰ ایپاک و در رزولوشن ۲۵۶×۲۵۶ آموزش داده شده
* نتیجه: mask mAP50 ≈ ۰.۲۰، mask mAP50-95 ≈ ۰.۰۶ (تک‌کلاسه، فقط تومور)

## نمونه نتایج

مدل به‌درستی تومورهای کبدی با اندازه و شکل‌های مختلف — از جمله نواحی تومورال نامنظم و چندلوبی — رو روی اسلایس‌های validation دیده‌نشده، لوکالایز و سگمنت می‌کنه.

## تک‌استک

* پایتون، TensorFlow/Keras (برای U-Net)، Ultralytics YOLOv11 (برای سگمنتیشن تومور)
* NumPy، OpenCV، Pillow، Pandas
* آموزش‌دیده روی Kaggle Notebooks (با GPU)

## بهبودهای آینده

* آموزش طولانی‌تر / بک‌بون بزرگ‌تر YOLO (`yolo11s`/`yolo11m`) برای بهبود recall تومور
* افزایش داده (data augmentation) متناسب با تصویربرداری پزشکی (با احتیاط در مورد flip هایی که جهت‌گیری آناتومیک رو خراب می‌کنن)
* استفاده از context سه‌بعدی (چند اسلایس) به‌جای پردازش مستقل اسلایس‌های دوبعدی
